# Пятёрка — копилка оценок

Небольшой дневник оценок с автоматическим подсчётом баланса за неделю и месяц.

## Правила

| Оценка | Изменение баланса |
| --- | ---: |
| 5 | +500 ₽ |
| 4 | +300 ₽ |
| 3 | −150 ₽ |
| 2 | −500 ₽ |

Оценку можно выбрать кнопкой или ввести с клавиатуры, указав сегодняшнюю или прошедшую дату. В истории можно переключаться между неделями (понедельник–воскресенье) и месяцами, смотреть все записи и удалять ошибочные. Удаление можно отменить сразу после него.

Данные сохраняются в `localStorage` браузера на текущем устройстве; аккаунт и сервер не нужны. Если очистить данные браузера или открыть приложение на другом устройстве, сохранённые оценки не перенесутся.

## Запуск

Нужен Node.js 20 или новее (для сборки Android используется Capacitor).

```bash
npm ci
npm run dev
```

Откройте адрес, который покажет Vite. Проверка расчётов и сборка:

```bash
npm test
npm run build
```

## Android: готовый APK

Приложение работает на Android 6.0 (API 23) и новее. [Скачать готовый Pyaterka.apk из GitHub Releases](https://github.com/tralaleotralaka-glitch/MARK-KALKYLYATOR/releases/download/android-v1.0.0-debug/Pyaterka.apk).

После каждого `push` запускается workflow **«Собрать Android APK»**. Чтобы скачать более свежую тестовую сборку:

1. На GitHub откройте вкладку **Actions** и выберите последний успешный запуск **«Собрать Android APK»** нужной ветки.
2. В разделе **Artifacts** скачайте **Pyaterka-APK** и распакуйте архив.
3. Перенесите `pyaterka-debug.apk` на телефон и откройте файл. При необходимости разрешите установку приложений из этого источника в настройках Android.

Для загрузки артефактов GitHub обычно требует войти в аккаунт. Артефакт хранится 30 дней. После появления workflow в основной ветке его также можно запустить вручную через **Actions → Собрать Android APK → Run workflow**.

Это **отладочный APK** для установки на устройство, не релиз для Google Play. GitHub создаёт временный отладочный ключ заново для каждой сборки, поэтому последующая сборка может не установиться поверх предыдущей. Удаление приложения удалит сохранённые в нём оценки. Для распространяемой версии нужен постоянный защищённый ключ подписи. Оценки из версии в браузере в Android-приложение автоматически не переносятся: у них раздельные хранилища.

## Локальная сборка Android

Дополнительно нужны JDK 21 и Android SDK с платформой API 35 и build-tools 35.0.0. Укажите путь к SDK через `ANDROID_HOME` (или `android/local.properties`), затем:

```bash
npm ci
npm test
npm run android:apk
```

Файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Для Windows после `npm run android:sync` запустите `gradlew.bat assembleDebug` из каталога `android` или соберите проект в Android Studio.
